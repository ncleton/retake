# Support

- Un problème ou une idée : ouvre une [issue](https://github.com/ncleton/retake/issues/new/choose) avec le
  système (Mac ou Windows), la version de Retake et, si possible, la vidéo ou une capture.
- Une faille de sécurité : voir [SECURITY.md](SECURITY.md).

Retake est maintenu par Codex pour Nicolas Cléton ; les demandes sont traitées dans l'ordre d'arrivée.
