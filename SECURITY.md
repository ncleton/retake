# Sécurité

Retake fonctionne entièrement sur l'ordinateur du relecteur : il n'envoie aucune donnée sur Internet. Les vidéos,
commentaires, images et enregistrements vocaux restent dans le dossier de l'application et dans le fichier .zip
que le relecteur choisit d'envoyer. Le micro n'est utilisé que lorsque le relecteur l'active.

Pour signaler une faille, utilise le [signalement privé de vulnérabilité](https://github.com/ncleton/retake/security/advisories/new)
de GitHub plutôt qu'une issue publique. Seule la dernière version reçoit des correctifs.
